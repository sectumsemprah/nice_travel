# 架构说明

## 分层

- `apps/web`：页面与 API 入口。
- `packages/shared`：共享类型与 Zod schema。
- `packages/domain`：纯业务规则，不依赖 Web 框架。
- `packages/providers`：外部服务适配器。
- `prisma`：目标数据库模型与迁移。

## 主链路

1. 创建旅行项目与偏好。
2. 导入合规旅行信息源。
3. 提取地点洞察并归一化为候选地点。
4. 基于偏好、日期和候选地点生成多日行程。
5. 生成路线快照。
6. 添加旅行素材并生成电子相册。
7. 创建只读分享链接或导出记录。

## Provider 策略

首版使用 Mock Provider 跑通流程。真实 Provider 必须满足：

- 明确授权或公开 API 来源。
- 保留来源引用。
- 具备超时、有限重试和错误分类。
- 不把敏感用户数据无差别发送给外部服务。
